# 👻 GhostSensix — Roblox Script Hub & Live Exploit Status

> **GhostSensix** is a modern, high-performance Roblox script hub, exploit status tracker, and loader distribution platform powered by Astral Violet cyber aesthetics.

---

## ⚡ Features

- **Astral Violet Cyber UI**: Responsive cyberpunk aesthetic with neon violet accents and glassmorphism.
- **Instant Script Loader**: Clean, one-click copy modal for Roblox Lua loader scripts.
- **Live Exploit & sUNC Status**: Real-time status indicators for Solara, Wave, Codex, and other major executors.
- **Sponsor Access Gate**: 24-hour access pass system with ShrinkMe monetization integration and VIP bypass.
- **Admin Management Portal (`/admin`)**: Thai-localized dashboard for managing scripts directly with Firebase Firestore.
- **Firebase Firestore Integration**: Real-time cloud database sync for script listings.

---

## 🚀 Getting Started

### Local Development Server

Run the included PowerShell server:

```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1 -Port 3001
```

Or double-click:
```
run.bat
```

- **Main Hub**: `http://localhost:3001/`
- **Admin Portal**: `http://localhost:3001/admin` (Default PIN: `admin888`)
